# sui faucet

## what is it?

its a simple testnet faucet which gives gas fees enough to cover multiple transactions 

## usage
open it in the browser

paste wallet address

click "Give me gas!"

and there you go.


## how to run it locally?

copy the commands:

```bash
git clone https://github.com/subhaintdead/sui-faucet
cd sui-faucet
```
and then if youre running it locally, you may add your credentials in a `.env` file, and change the `data-sitekey` from `index.html`
